## 已确认需求保留检查

- 免费共享；默认 USD；记录使用者与分享者的用量和估算成本。
- 六类 AI API 与多协议接入；不扩大为任意 HTTP API 平台。
- 分享分组可命名；同一模型在广场聚合，详情展示分享者和分享名称。
- 一键发现模型、手动补充；价格同步只复用 New API，并保留人工补价与覆盖。
- 指定分享来源、延迟优先、吞吐优先、六小时可靠性优先及综合自动。
- 渠道与 Key 的并发、速率、预算和共享账户限额共同参与调度。
- 多 Key 导入、轮询等策略、独立状态和消耗统计。
- 邀请/邮箱注册配置；公开、受限、指定用户及仅自己使用。
- 接受 New API 的开源改造路线，保留相应许可证和署名义务。
