# 开源发布说明

更新日期：2026-11-17。

## 发布内容

本仓库包含 APIGX 应用源码、构建文件、部署示例与验证脚本。应用源码位于 `new-api/`，前端使用 Bun，后端使用 Go。项目基于 New API 二次开发，保留上游提交历史、许可证与署名。

工具中心当前使用自建服务商审计、速度测试和模型掺水检测流程；早期 manxue 接入已经下线。掺水检测按已校准的基准与档位采样，并支持将上游请求别名与比较基准分别指定。

## 许可范围

- 应用代码：AGPLv3，详见根目录与 `new-api/` 中的 `LICENSE`。
- 上游署名及声明：`new-api/NOTICE`。
- 内嵌 `meow-*` 指纹基准：PolyForm-Noncommercial-1.0.0，详见 `new-api/THIRD-PARTY-LICENSES.md`。
- 自采基准与校准报告：来源及适用范围见同一第三方许可文件。

公开源码不改变第三方数据的许可。当前包含非商业基准的构建不能被描述为允许不受限制的商业使用；商业分发前需替换这些数据或取得授权。自采工具位于 `new-api/cmd/fingerprint`，采集结果需要重新校准，不能直接假定和旧基准等价。

## 验证边界与已知限制

- 以实际执行的测试结果为准；不把历史验证当作每个后续提交均已重新通过。
- 先前一次全量前端测试记录中，Markdown 链接渲染相关的 `plugin-changelog-panel.test.tsx` 有 2 个失败，本次发布准备不宣称全量套件全绿。
- 模型检测会消耗用户上游额度，结果依赖样本、基准、协议与上游状态，不构成模型身份认证。
- 自采基准通过中转接口采集，其标签不独立保证上游是官方直连。
- 本次源码发布不包含生产环境部署、正式容器镜像发布或对生产上游的付费采样。

## 配置与数据

模板中的密码和密钥仅为占位或本地示例，使用前必须替换。真实 `.env`、密钥、数据库、日志、本地工具链和开发过程记录不属于发布内容。部署时应持久化数据、独立备份凭据加密主密钥，并配置 HTTPS、可信代理与 Cookie 策略。

根目录 README 提供源码构建方式；`new-api/docker-compose.yml` 默认使用上游 New API 镜像，部署 APIGX 时需要改用本项目的构建产物。
